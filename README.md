# Eduardo Paim · portfólio

Site pessoal publicado em <https://eduardopaim5.github.io/> (versão em inglês em `/en/`).

Um templo grego em forma de site: o lintel com o nome, quatro pilares (Projetos, Sobre, Recrutadores, Contato) e, atrás do pilar de projetos, uma órbita com os demais trabalhos cujo tamanho e velocidade vêm de dados reais do GitHub.

- `index.html`, `en/index.html`: páginas geradas (HTML, CSS e JavaScript sem dependências).
- `data/orbit.json`: commits e última atividade de cada projeto, atualizado diariamente por `.github/workflows/orbit.yml` com `scripts/github_stats.py`.
- `media/`: gravações e capturas dos projetos.
